# Mathematical Models in Biology: Reaction-Diffusion Equations

This repository contains a LaTeX document and associated Julia scripts for generating figures in a report on mathematical models in biology. The report explores reaction-diffusion partial differential equations, focusing on the Fisher-KPP equation and the Allee effect model, including analytical derivations of travelling wave solutions and phase portraits.
